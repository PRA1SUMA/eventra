# Eventra 🌍

Eventra is a location-based event discovery platform that helps users find events around them using a map interface.

## 🚀 Tech Stack

- Frontend: Next.js (React)
- Backend: FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy

## 📍 Features (Current Progress)

- User Authentication UI (Sign In / Sign Up)
- Event API (Create & Fetch Events)
- Full-stack architecture setup
- GitHub version control

## 🧠 Upcoming Features

- GPS-based user location tracking
- Interactive map with event pins
- Event details popup
- Route navigation to events
- User profile & history

## 🛠️ Project Status

This project is under active development as part of a learning + portfolio build.
